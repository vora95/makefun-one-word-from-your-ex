One word an ex would use to describe you: **placeholder** — never the destination, only the seat kept warm until someone better came along. Funny because it makes you a role, not a person; painfully honest because it says the whole relationship was provisional.

## Run it

```sh
node main.ts
cat /output/entry.txt   # placeholder
```

`main.ts` is a deterministic program (no clock, no randomness, no network, no input). It writes the single word to `/output/entry.txt` — exactly 11 bytes, no trailing newline, inside the competition gate of 1–24 characters.
